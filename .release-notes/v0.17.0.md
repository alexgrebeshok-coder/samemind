## samemind 0.17.0 — contract locked, dogfood measurable

The release before the freeze. 1.0's defining promise is that the JSON shape stops moving — after
it, a changed field is a major version. So this release writes the contract down, locks it with
tests, cleans up the shapes we would have regretted, and builds the instrument that can actually
answer "has it run clean for a week?".

Merged via PR #10 (`auto/release-0170`).

### Added

- **`docs/json-contract.md`** — every surface, its `kind`, the keys of `data`, the error shape,
  and what counts as a breaking change.
- **`tools/contract-shape.test.mjs`** — key-presence assertions for every payload.
- **`samemind dogfood`** — days without an open failure of our own, what the last one was, and
  whether it is closed. On a bundle with no history it says **"nothing to measure"**, never
  "0 failures".
- **Self-failures reach the ledger** — `writeHealth` appends to topic `samemind-health`.
- **A `samemind` entry in the fleet registry**, `heartbeatSec` 604800 — one dogfood week.
- `generatedAt` on `status`, `fleet status`, `ledger status`, `query links`, and `proactive --json`.

### Fixed

- **Payloads carried the machine and the whole corpus** — `board` and `handoff` shipped absolute
  paths and full markdown bodies. On the live bundle `board` went from **160,833 to 23,123 bytes**.
- **Truncated arrays now state their totals** — `board.sessions`, `handoff.sessionNext`, the SSE
  snapshot and `ledger.topics[].evs` were silently capped.
- **One key set per payload** — `assessAvailability` and `doctor` branches now use explicit `null`.
- **`node` and `platform` left the doctor payload** — they stay in the human output only.
- **A test wrote into the shipped demo bundle** — `POST /api/config` was aimed at `demo/`.
- README claimed four screens where there are seven and zero write endpoints where `POST
  /api/config` exists.

### Not yet

1.0 is not tagged. The owner's condition — a clean dogfood week — is now measurable for the first
time, and the clock starts when the instrument starts recording, not retroactively.
