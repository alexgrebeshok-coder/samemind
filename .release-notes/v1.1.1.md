## samemind 1.1.1 — `--root` for query and recall

Patch. Closes the hole 1.1.0's smoke test found: two of the CLI's read commands
ignored `--root` outright. Same defect class 1.0.1 already fixed once for `board`
and `handoff` — this time it hit `query` and `recall` too.

### Fixed

- **`--root` now works on `query` and `recall`.** Both parsed the flag into nothing:
  `query`/`recall` read `OKF_ROOT`/cwd regardless of `--root`, so `okf-query --root
  ./other-bundle list` (or the `recall` equivalent) silently reported on the wrong
  bundle — a plausible-looking result, exit 0, no sign anything was off.
- **A `--root` that is not a real directory now fails loudly.** Nonexistent path,
  or a path that resolves to a file, is an error naming the path — not a quiet
  empty result.
- **A flag with no value now fails loudly.** `--root` at the end of the command
  line, or immediately before another flag, is "needs a value", not a silent
  fallback to the default bundle.
- **An unknown flag on `query`/`recall` is now an error with a non-zero exit.**
  Previously any unrecognized `-`-prefixed argument was silently ignored. A script
  with a stale or mistyped flag will now fail instead of quietly running with that
  flag dropped — same change 1.0.1 made for `board`/`handoff`.

### Named limitation

`--root` combined with an explicit semantic mode is refused, because the
embeddings index is pinned to the default bundle, not to whatever `--root` points
at — recall has no way to consult a foreign bundle's vectors. `auto` degrades
instead of refusing, since it never explicitly asked for semantics. Exact text:

- `--mode semantic` or `--mode hybrid` with a different `--root`:
  > `--mode semantic does not support --root yet (the semantic index is pinned to the default bundle, not <root>) — use --mode bm25, or drop --root and run from inside that bundle`
- `--mode auto` (the default) with a different `--root`, to stderr, then proceeds on BM25:
  > `note: --root given — auto uses bm25 only here (semantic index is pinned to the default bundle, not <root>)`

Plain `--root` (no mode, or `--mode bm25`) is unaffected — BM25 ranks straight off
the loaded docs, not the cached index, so it is correct against any bundle.

### Internal

- `resolveBundleRoot` existed as two byte-identical copies, one each in `board.mjs`
  and `handoff.mjs` — the exact function `query`/`recall` needed, already written
  twice. A third and fourth copy would have been the same defect class 1.0.1 fixed,
  reintroduced by hand. It now lives once, in `tools/lib/bundle-root.mjs`, with four
  callers instead of two copies of the logic.

### Unchanged

- CLI/HTTP JSON envelope and every field under `data` — byte-identical to 1.1.0.
- MCP tool shapes — untouched.
- Recall without `--root` (the default, unaffected path) — byte-identical to 1.1.0.
